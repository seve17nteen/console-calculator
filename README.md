# ConsoleCalculator

Консольный калькулятор на Qt (QtCore) с использованием сигналов и слотов
и парсером CSV-файлов для вычисления суммы и среднего по каждой строке.

## Возможности

### Калькулятор
- Сложение, вычитание, умножение, деление
- Обработка деления на ноль
- Обработка неверного ввода
- Сброс состояния

### CSV-парсер (индивидуальное задание, средний уровень №13)
- Чтение CSV-файла с числами
- Поддержка разделителей `,` и `;`
- Вычисление суммы и среднего по каждой строке
- Сигнал `lineProcessed` — на каждую успешно обработанную строку
- Сигнал `lineError` — при ошибке в конкретной строке
- Сигнал `finished` — по завершении файла (всего строк, общая сумма)
- Сигнал `errorOccurred` — при общей ошибке (файл не открылся и т.п.)

## Требования

- Qt 5.x или Qt 6.x (модуль Core)
- qmake
- Компилятор C++17

## Сборка и запуск

```bash
qmake ConsoleCalculator.pro
make        # или mingw32-make / nmake
./ConsoleCalculator
